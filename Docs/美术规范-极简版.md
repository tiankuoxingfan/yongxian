## 0. 一句话风格

**黑白线稿纸面 + 只给"能动的"上色。**
画面 95% 是墨线黑白，只有交互物带颜色 —— 颜色本身就是引导玩家"这里能碰"的信号，同时也是把美术产能压到最低的手段。

参考气质：《饥荒》的墨线松弛感 + 《星露谷》的俯视比例，**不要**往日系厚涂走。

## 1.1 主角与神明视觉设定（v1.2 定稿，以设计图为准）

**基准图：`Docs/reference/角色设计图-v1.jpg`（2026-10-13 美术提供，含主角立绘、修普诺斯立绘、Q 版草稿）**

### 主角 · 三十岁女性社畜（鬼魂态）

一句话气质：**一个累到死了还在被使唤的打工人。** 是"狼狈但清醒"，不是美少女，也不是搞笑丑角。

以设计图为准的 6 个识别点（**比我上一版写的更准，按这个画**）：

| # | 特征 | 备注 |
|---|---|---|
| 1 | **黑色西装外套 + 黑色及膝裙** | 主色即墨黑 `#1C1B18`，天生贴合黑白世界 |
| 2 | **白衬衫**（领口敞、没塞好） | 纸白 `#F0F0F0`，同上 |
| 3 | **眼镜**（细框，镜片微反光） | 设定图关键识别点，所有朝向必须保留 |
| 4 | **黑色凌乱短发**（碎发翘起） | 不是丸子头/马尾 —— 推翻我 v1.1 的写法 |
| 5 | **蓝色文件夹**（抱在身前） | **她全身上下唯一的彩色**，也是世界内玩家的识别标记，必须保留 |
| 6 | **黑色高跟鞋** + 疲惫半眯眼 | |

> **设计亮点**：主角的黑西装+白衬衫=墨黑+纸白，她天然"长在"黑白线稿世界里；蓝色文件夹是她唯一的彩色，让玩家在俯视全景里**永远一眼找到自己**。这与 §2 的取色策略完美咬合，请务必保留，别给主角加其他颜色。

### 表情差分（分工表 #12，4 个）

按文案情绪极值定，不做通用四件套：

1. `player_face_01` **茫然** —— 开场被神叫住，一脸"？"
2. `player_face_02` **暴怒** —— 「你个破烂神还想让我死了也接着加班？？」
3. `player_face_03` **谄媚滑跪** —— 听到能救妹妹后瞬间变脸
4. `player_face_04` **无奈 / 认命** —— 被咪咪吐槽的日常脸

表情差分在立绘尺寸（1024 px 高）上画，**幅度要大**；世界内 58 px 精灵只保留 1–2 个。

### 修普诺斯（新增 —— 他有立绘了，推翻文档三"不建模"）

设计图确认：**白发（米金）长发少年 + 白色希腊褶裙（chiton）+ 背生白色双翼 + 月桂头环 + 赤足**，手持牧羊杖。

- 只出**立绘 + CG**，世界内仍用幻象表现（半透明白色 + 程序化云雾），**不做俯视精灵、不做动画** —— 省下整套工时，与文档三成本原则一致
- 立绘交付：`hypnos_body.png` + `hypnos_face_01..04.png`（PSD 分层）

### 咪咪（边境牧羊犬）

黑白相间 —— **天然匹配六色板里的墨黑 + 纸白**，不用额外设计配色。

### 鬼魂的脚下阴影（与 §4 冲突，此处为准）

- 保留椭圆阴影，**不透明度降到 12%**（其他角色 25%），边缘羽化
- 精灵**离地 2–3 px**，阴影不跟随浮动
- 走路时上下正弦浮动 **±2 px，周期 0.6 s**

这样既保住 Y 轴排序参考点，又能一眼看出她不是活人。
其余角色照 §4 正常 25% 实心阴影。

## 2. 颜色（六色板，不许超出）

| 用途 | 色值 | 用在哪 |
|---|---|---|
| 纸底 | **`#F0F0F0`** | 场景底、UI 底、羊身留白 |
| 墨黑 | `#1C1B18` | 全部线条、文字、剪影 |
| 爱琴海蓝 | `#3A7CA5` | **水**、水枪、水源、水羊 |
| 神力金 | `#C89A2B` | **神力**、祭坛、收集反馈 |
| 陶土橙 | `#C4622D` | **火**、火盆、圣火羊 |
| 橄榄绿 | `#6B7C3A` | 植被、葡萄架、芦苇（弱引导） |

### 取色策略（这是全项目最硬的一条规则）

- **场景内**：只有**可交互物**上色。水源=蓝、火=橙、神力=金，其余一律黑白灰。
- **唯一例外 —— 主角**：她的蓝色文件夹是全图唯一的随身彩色，作用是让玩家在俯视全景里一眼认出自己。除此之外主角仍然只有墨黑+纸白。
- **不上色的东西**：地面、建筑、柱子、台阶、山体、草丛、天空、UI 底框 —— 全灰。
- 灰阶只能用 `#F0F0F0` → `#1C1B18` 之间的中性灰，**不许偏色**（不许灰里带蓝、带黄）。

> ⚠️ **纸底以 `#F0F0F0` 为准，不是 `#F5F1E8`。**
> 文档四里同时出现了这两个值，但 `#F0F0F0` 是**现有素材**的实际色。新画的场景要和已有素材拼在一起，改存量素材的成本远高于改新画，所以统一到 `#F0F0F0`。

### 羊的可交互高亮（分工表 #51）—— 不许用颜色

蓝/橙/金已经被"水/火/神力"占满语义了，高亮再上色会误导玩家。

**做法**：在羊身上叠一层**白色外描边（2 px）+ 0.8 秒呼吸脉冲**，墨线本身加粗到 4 px。色相不动，只动明度。
交付：`sheep_highlight_01..04.png`，叠加层，锚点同羊。

## 3. 线稿规范

| 项 | 值 |
|---|---|
| 线条颜色 | 纯墨黑 `#1C1B18`，**不许**用彩色线、不许用深灰描边 |
| 外轮廓 | **4 px**（描边勾一圈） |
| 内轮廓 | **2 px** |
| 线条端点 | 圆头、允许轻微抖动 1 px，保留手绘感 |
| 抗锯齿 | 保留，不要做硬边像素风 |

**不要**：渐变网点、阴影排线、材质纹理、外发光。要"印刷感"，不要"厚涂感"。

## 4. 光照与阴影

- 光源方向：**统一右上 45°**，全场景一致，不许出现第二个光源方向。
- 落地阴影：脚下**椭圆**，填充 `#1C1B18` **透明度 25%**，长轴 : 短轴 ≈ 2 : 1，锚点 `Center`。
- 物体投影一律往**左下**偏移，偏移量 ≈ 物体高度的 20%。
- 不做环境光遮蔽、不做彩色阴影。

## 5. 分层与排序

程序用 **Y 轴排序**（`Transparency Sort Axis: 0, 1, 0`），美术只管分文件夹和给图层号。

| Sorting Layer | 内容 | Order in Layer |
|---|---|---|
| Background | 天空、远山、远景建筑 | 0 |
| Midground | 地面、主建筑、柱廊 | 0（靠 Y 排序） |
| Shadow | 所有脚下椭圆阴影 | 0 |
| Actor | 羊 / 玩家 / 咪咪 / NPC | 0（靠 Y 排序） |
| Foreground | 前景遮挡（芦苇、栏杆） | 0 |
| FX | 水柱、粒子、掉毛、扬尘 | 10 |
| UI | 全部界面 | 100 |

**Y 轴排序基准点 = 脚下锚点**，不是精灵中心。画的时候底部对齐，别留透明边。

场景分层交付（分工表 #45）必须另附一张**可行走区标注图**：可行走=半透明绿，阻挡=半透明红，单开图层，程序照着摆碰撞体。

## 6. 朝向与动画（分工表 #47 / #50 需修正）

文档五写"转向 8 向瞬时"，但分工表只列了"左右朝向 ×2"。**2 向不够用**，玩家斜着走会瞬移。

**修正为 4 向**，命名用方位不用左右：

| 后缀 | 方向 | 做法 |
|---|---|---|
| `_S` | 朝下（面向镜头） | 原画，正脸 |
| `_N` | 朝上（背对镜头） | 原画，后脑勺 |
| `_E` | 朝右 | 原画，侧面 |
| `_W` | 朝左 | **`_E` 水平镜像即可**，不用重画 |

即：**每个动作实际只画 3 向（S / N / E），W 由 E 镜像生成**。工时按 ×3 算，不是 ×2。

- 主角：走路 / 待机 / 喷水 / 推 / 拉 —— 全套 ×3 向
- 羊：走路 / 吃草待机 / 正常待机 / 被推惊慌 —— ×3 向
- 咪咪：走路 / 待机 —— ×3 向

> 分工表 #47（角色左右朝向，2 个，3h）和 #50（羊左右朝向，2 个，2h）建议改成 4 向，工时各 +50%。这条要重新排。

## 7. 立绘与 CG（单独放宽，但仍限六色板）

场景内严格黑白；但**立绘 / CG 允许上色**，否则主界面会寡到没人看。

放宽范围：允许使用**陶土橙 + 橄榄绿 + 爱琴海蓝**做服饰与背景，**纸底 + 墨黑**仍是主调，**神力金**只留给神力相关元素。

| 素材 | 尺寸 | 交付 |
|---|---|---|
| CG·主界面 | 1920 × 1080 | PSD 分层 + PNG |
| CG·设置 / 存档底图 | 1920 × 1080 | PSD + PNG |
| 对话框底框 | 九宫格切片，中宫 ≥ 64 × 64 | 9-slice + PSD |
| 神 / 酒神 / 玩家 / 狗 立绘 | 高 1024 px，透明底 | PSD 分层 + PNG |
| 表情差分 | 与立绘同尺寸，只换脸 | PNG，`{角色}_face_01.png` |

**表情差分只需画脸，身体复用立绘** —— 画的时候脸单独一个图层，别合并。

## 8. 命名与目录

```
Assets/Art/
├── Character/{角色}/      player_body.png  player_face_01.png  player_walk_S_01.png
├── Sheep/                 sheep_walk_E_01.png  sheep_panic_S_01.png  sheep_highlight_01.png
├── Scenes/L1/ …           scene_L1_bg.png  scene_L1_mid.png  scene_L1_walkable.png
├── Props/                 icon_water.png  icon_gun.png  icon_dryer.png  icon_pump.png  icon_push.png
├── FX/                    fx_gun_01.png  fx_wool_01.png  fx_leaf_01.png  fx_dust_01.png
└── UI/                    ui_button_normal.png / _pressed.png  ui_hud_slot.png
```

命名规则：
- 动画：`{对象}_{动作}_{朝向}_{序号}.png`，序号 **两位补零**，从 `01` 起
- 特效：`fx_{名称}_{序号}.png`
- 图标：`icon_{道具}.png`，选中态 `_sel`，禁用态 `_dis`
- 朝向后缀：`_S` / `_N` / `_E` / `_W`
- 全小写，只用下划线，不许空格、中文、大写

**导出**：一律 **PNG-24 透明底**，不合并图层，PSD 源文件同目录另存。

### 7｜世界内的精灵，跟不跟立绘一起转彩绘？（⚠️ 最重要，还没拍板）

10-13 的角色设计图是**全彩水彩厚涂**（主角有肤色、蓝文件夹、金色头发），而 GDD 文档四的场景是**黑白墨线 + 只给交互物上色**。两条路线只能选一条：

**方案 A：世界内保持黑白墨线（推荐）**
- 俯视场景、羊、玩家精灵、UI 全部黑白线稿；立绘 / CG / 主界面用彩绘
- 主角的黑西装白衬衫在黑白世界里毫无违和，蓝色文件夹成为她唯一的彩色标记
- 彩色只出现在：水（蓝）、火（橙）、神力（金）、主角文件夹（蓝）
- ✅ 美术工时可控（96h 装得下）｜✅ 保留"稀缺颜色即引导"的核心设计｜⚠️ 立绘和场景是两种气质，主界面 CG 需要用纸白+墨黑把两边"缝"起来

**方案 B：全面转彩绘 Q 版**
- 场景、羊、精灵全部跟立绘同一套彩绘
- ✅ 和立绘统一、第一印象更讨喜
- ❌ 场景 + 羊 + UI 全要上色，96h 根本装不下（至少 ×2 工时）｜❌ "稀缺颜色做引导"这个差异化设计没了，可交互物和背景全靠造型区分，玩家学习成本上升

**我的建议是 A**：7 天 Jam、3 个美术、96 小时，A 是唯一能在 Deadline 前跑完的路线；而且"满屏黑白里的一点颜色"本身就是这个游戏最有辨识度的画面记忆点。**但在你点头之前，我不把这条写死。**

## 11. 排期风险提醒

- **高优先级项合计 53.5 h，全部截止 10-14（前 24 小时）**，3 人理论产能 72 h —— 能塞下，但没有任何容错。
